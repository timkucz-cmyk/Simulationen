Stimmt die Lösungsmenge?

Zieh x über die Zahlengerade. Jede getestete Zahl hinterlässt einen Punkt: grün, wenn die Ungleichung wahr ist, rot, wenn sie falsch ist. Vergleiche die Zeilen.

Zweck
Demonstration am Beamer im Unterrichtsgespräch (eine Person bedient, die Klasse sagt voraus). Teil 1 zeigt, warum das Relationszeichen beim Multiplizieren mit einer negativen Zahl umgedreht werden muss: Mal eine negative Zahl spiegelt an der 0, dadurch tauschen die Punkte ihre Reihenfolge. Teil 2 macht Lösungsmengen sichtbar und entlarvt den typischen Fehler (nicht umgedreht).
Vorwissen
Äquivalenzumformungen bei Gleichungen; Begriff Ungleichung und Lösungsmenge (kurz vorher eingeführt); Tabelle „Bleibt es wahr?“ mit 2 < 6 im Heft.
Ablauf (ca. 7 min + 3 min)
Teil 1: a = 2, b = 6. Faktor 3, 1, 0,5 zeigen (Abstand ändert sich, Reihenfolge nicht). „Nachher verdecken“ einschalten, Faktor −1 einstellen, Vorhersage per Handzeichen, aufdecken. Danach Faktor langsam von 1 bis −2 ziehen: Bei 0 fallen beide Punkte zusammen, danach liegen sie gespiegelt. Zum Vergleich „+ Zahl“: Verschieben ändert nie die Reihenfolge.
Teil 2: Leas Rechnung (−2x + 5 < 11 → x < −3) mit „Alle Zahlen testen“ prüfen; die Zeilen passen nicht zusammen. Korrigierte Zeile stimmt mit der Ausgangsungleichung überein.
Hinweise
Keine Eingaben werden gespeichert. Faktor in Viertelschritten von −3 bis 3, Schnellwahl für typische Werte. Auf dem Lehrerrechner im Vollbild (F11) gut lesbar.
